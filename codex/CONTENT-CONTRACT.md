# Codex Content Contract

Этот файл предназначен как краткая обязательная инструкция для Codex при работе с учебным контентом.

## MUST

Codex MUST:

1. следовать `docs/content/COURSE-CONTENT-SPEC.md`;
2. сохранять существующие стабильные `id`;
3. хранить материалы курса в Markdown;
4. хранить каждую задачу в отдельном `.md`;
5. использовать YAML Front Matter;
6. использовать LaTeX для математических формул;
7. использовать локальные изображения;
8. использовать обычные HTTPS URL для внешних ссылок и видео;
9. не использовать raw HTML;
10. не добавлять `<iframe>`;
11. не помещать решения преподавателя в `problem.md`;
12. не смешивать контент и состояние LMS;
13. после изменений запускать Course Validator;
14. исправить все `ERROR` до завершения задачи.

## SHOULD

Codex SHOULD:

- делать минимальный diff;
- не менять `id`, если сущность остаётся той же;
- использовать понятные имена каталогов и файлов;
- сохранять переносимость Markdown вне LMS;
- не вводить новый DSL без отдельного архитектурного решения.
