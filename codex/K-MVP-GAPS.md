# K — MVP contract gaps

Inspected actual Domain/Application DTOs, PublishedContent, queries, access facts,
content specification §9 and frontend consumption. Estimates are implementation/testing
ranges for one engineer, not commitments. No unsourced product features implemented.

| Gap | Current contract / user impact | Minimal solution, privacy boundary | MVP recommendation / priority / estimate |
|---|---|---|---|
| Reference solutions | `PublishedProblemContent` has id/order/title/statement only; no ProblemRevision aggregate or stored solution relation. Assignment has exact CourseVersionId/LessonId/ProblemId. Content spec suggests separate `.solution.md`, excludes solutions from student artifact. Teacher DTO has no field. Teacher must use separate material. | If needed, provision separate version-keyed teacher artifact; authorize by current course/group before a dedicated read DTO. Never insert secret solution in shared `ContentJson` or student DTO and hide via CSS. | **P2**, defer for a small pilot if teachers already have answers externally. Otherwise 3–5 days including leakage/version tests; decision requires pilot owner. |
| Assessment criteria | No rubric/scoring entity or trusted criteria field in compiled content/DTO. Feature concerns accept/revise, not scoring. | Teacher-only Markdown material tied to exact version is sufficient; use existing external teacher materials for pilot. No new scoring model. | **P2**, defer; 1–3 days once source is agreed. Absence does not break accept/revise. |
| Student display names | `UserSummaryDto` supports nullable displayName; queue explicitly projects null. No Person/Student profile repository, names or directory binding. Teacher sees UUID. | Trusted identity/profile mapping; bulk join/projection per page, no per-row external calls. Return minimum name only within authorized roster; names never expand queue scope. Do not turn JWT display-name claims into trusted enrollment. | **P2 with restricted-roster workaround** (secure roster mapping outside app). Resolve **before a larger pilot** where UUID ambiguity prevents reliable identification; 2–4 days after source choice. |
| Filter catalogs | Course workspace requires known courseId; Group represented only by access strings, no courses/groups/students lookup endpoints. Queue summary byCourse is filtered results, not complete catalog. | Scope-aware read-only lookups from access grants/enrollments/content versions; courses/groups/students only inside teacher scope, batch labels. Until then document IDs on secure pilot roster. | **P2**, defer small pilot, resolve before wider use; 2–4 days with identity source. |
| Teacher screen role boundary | C4 general own-work GET intentionally allows Student; legacy screen displayed it read-only, contrary to K teacher-screen criterion. | K adds role-gated `/teacher/problem-works/{id}`, same DTO and existing authorization. General API remains compatible. No new role/workflow. | **FIXED**, two role/scope/terminal regression cases + browser denial. |
| Provisioning and sign-in | Development seed only; frontend host requires `lmsAuth`; no real IdP/roster publication/deployment session integration exercised. | Configure trusted UUID/role mapping, real students/grants/immutable content, host session remount. Run end-to-end with real staged identities. | **P1 RELEASE BLOCKER**, before any real-data pilot. Estimate after IdP/source decision, not invented. |
| History payload / Lesson N+1 | Whole history included in workspace; History loads all photos, no pagination. Lesson resolves content/availability per assignment; Course resolves content per lesson. | K eliminates Cartesian history queries while keeping snapshot consistency. Future bounded/lazy history and batched lookups only after capacity/usage requirements agreed. | **P2**, measured and explicit in performance report; do not label these as solved by split queries. |

No recommendation here grants readiness: authentication, backup/recovery, exposed-service
resource protections and intended real-device validation remain independent release gates.
