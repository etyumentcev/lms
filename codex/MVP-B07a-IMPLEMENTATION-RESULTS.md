## Components and accepted documentation

[Compiler](../tools/content_compiler/compiler.py) implements all six schemas, inventory, IDs, structure, orders, targets, material cardinality, asset ownership/visibility, independent projections, reachable manifests, deterministic JSON and SHA-256. [Snapshot](../tools/content_compiler/snapshot.py) uses Linux no-follow root traversal and openat2 RESOLVE_BENEATH/RESOLVE_NO_SYMLINKS, regular-file/link-count checks, bounded reads, identity/tree/byte rechecks. Compilation then uses retained bytes only.

[YAML parser](../tools/content_compiler/yaml_input.py) rejects ambiguous/duplicate/tagged/aliased input and retains scalar/key coordinates. [Markdown processor](../tools/content_compiler/markdown.py) uses CommonMark AST, validates inline/reference/autolinks and unused definitions, excludes code and rewrites only destinations. [Model](../tools/content_compiler/model.py) provides closed stable diagnostics and JCS for the output contract's restricted domain: ASCII keys, Unicode strings, safe integers, arrays, booleans/null; no floats.

[Legacy validator](../tools/content_compiler/legacy.py) is separate: unknown fields warn without new semantics, cross-lesson problem IDs warn, internal symlinks/local Markdown links remain allowed. Legacy compile returns E_REVISION_REQUIRED plus separate validation. No historical executable validator existed; compatibility means written v1 semantics and fixtures, not equivalence to an unavailable binary.

[CLI](../tools/content_compiler/__main__.py) stages private bundles and exposes both using renameat2(RENAME_NOREPLACE); no overwrite or partial output after validation/staged-write failure. ## Limitations and recommendation

The previously reported math gap is closed in `sapientum-python-2`: [math AST/validator](../tools/content_compiler/math_validation.py), fixed [KaTeX checker](../tools/content_compiler/math-check.cjs), pinned [dependency](../tools/content_compiler/package.json), and eight [math tests](../tests/content_compiler/test_math.py). Inline/display formulas are separate AST nodes, source text is preserved, and Markdown-like text inside math is not an asset dependency. KaTeX 0.16.47 validates syntax with strict errors, fresh per-expression macros, bounded expansion and denied trust. Unsafe URL/HTML/image commands, unknown commands, unclosed delimiters and private math errors deny both artifacts. Missing runtime/version fails before package reads; subprocess timeout/internal failure is closed. No shell, resource fetching or input-as-JavaScript execution. New diagnostic E_MATH identifies the formula opener without disclosing formula text.

Math validation is the safe KaTeX subset, not arbitrary executable TeX or mathematical truth. Browser visual equivalence remains an integration check. Compiler revision changed because parsing behavior changed; the N9 projection/package/teacher hashes remain identical, while buildMetadata.compilerRevision is now sapientum-python-2. Earlier compiled/ evidence is retained as historical revision-1 output.

Recommendation: accept B07a as an offline synthetic component within the documented platform/dependency limits. Owner acceptance is not presumed. No B07b/B08, publication, HTTP or pilot authorization is implied.

Linux openat2 is required; unsupported platform/kernel fails closed. x86_64 tested, aarch64 not tested. Privileged hostile mounts/malicious filesystems and hard operational time bounds are not proved. CLI output parent is trusted caller-controlled storage; atomic visibility is not crash durability. PDF deliberately rejected until safe checking is proven. Pillow verifies/decodes raster formats and rejects decompression bombs; semantic secrecy remains author responsibility.
