# L0.2 — Controller / processor model

2026-10-09. **REQUIRE LEGAL REVIEW. Compliance status: NOT VERIFIED. Pilot readiness: NOT_READY.**

Рабочая гипотеза: организация A определяет цели учебной обработки, ООО P исполняет поручение A. P может быть самостоятельным оператором для отдельно установленных собственных целей. Для собственных курсов B то же ООО является организатором и оператором соответствующих учебных ПД; второе юридическое лицо и поручение самому себе не требуются. Это не окончательная юридическая квалификация. Технические данные не автоматически принадлежат P в юридическом смысле.

## Матрица ответственности

T1–T6 — категории [inventory](PD-DATA-INVENTORY.md), численные сроки не утверждены. Authority означает полномочие принять решение с учётом закона и прав субъекта; исполнитель назначается отдельно.

Policy/subject basis версионируются по [ProcessingContext](../architecture/PROCESSING-CONTEXT-MODEL.md). Организации не получают чужие memberships по ActorId.

## Договор A ↔ P: требования и проекты положений

Неподписанные заготовки для юриста. Договор предоставления LMS и поручение могут быть связанными документами/разделами; название SaaS само по себе не определяет роли.

| Раздел | Проект положения / обязательное уточнение |
|---|---|
| Роли | «A организует обучение и определяет цели учебной обработки; P выполняет документированные поручения в согласованном объёме». Сверить фактические решения сторон |
| Предмет поручения | Приложение: цели, категории субъектов/ПД, операции сбора/хранения/выдачи/блокирования/уничтожения, context versions; проверить право поручения и необходимость согласия/иного основания |
| Ограничения | «P не использует учебные ПД для самостоятельной аналитики, рекламы или AI по этому поручению». Собственные цели оформляются отдельно |
| Защита | Конфиденциальность, меры безопасности, локализация, допуски персонала, предоставление A документов о мерах до обработки и по запросу; действующие требования проверяет юрист/ИБ |
| Подрядчики | Список VPS/backup/support, операции/территории/доступ, порядок согласования изменений и цепочка обязательств; не blanket permission любому субподрядчику |
| Технический доступ | Именные ops/issuer, временный support grant с целью/resources/expiry/audit/reviewer; заранее ограниченная emergency процедура |
| Инциденты | Сдерживание/evidence, канал/заместитель, передача сведений A в договорный срок внутри применимого законного срока; обязанности перед органами определить по каждой роли |
| Обращения | Приём/маршрутизация A и P, проверка представительства, решение controller и исполнение processor, сроки forwarding не поглощают законный deadline |
| Lifecycle | Scoped manifest, lawful retained subset, все копии/подрядчики, подтверждение уничтожения; A не распоряжается данными B |
| Прекращение | Protected return/export, остановка обработки, сроки удаления DB/files/backups, evidence; неоплаченный счёт не основание вечного хранения работ |
| Контроль | Ответственность в пределах закона, аудит, контакты, версии/изменение поручения, подписи; права субъектов договором не отменяются |

## Собственные курсы P ↔ родители/ученики

Нужны отдельные условия обучения, основания/информирование, проверка стороны договора и представительства, канал обращений, сроки. Класс 5–8 не доказывает возраст/дееспособность: PD-G03 остаётся открытым. Согласие применяется по конкретной цели, не заменяет договор или лицензию. Данные A не переносятся на собственные курсы P автоматически.

Проверить № 273-ФЗ по реальным программам/статусу организации: статьи 2, 21, 31, 54, 91 и действующее положение о лицензировании. Статья 91 предусматривает лицензирование образовательной деятельности; исключение для непосредственно обучающего ИП не является исключением для ООО. Дистанционный формат сам по себе не освобождает от требований. Для A до пилота и P до запуска собственных программ требуется legal applicability memo и необходимая лицензия либо мотивированная неприменимость. Licensing UI в LMS не вводится.
